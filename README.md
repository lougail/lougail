**[Flight Platform](https://github.com/lougail/hello-mira-flight-platform)**<br>

`FastAPI` `MongoDB` `LangGraph` `Mistral` `Prometheus` `Docker`

**[Veille tech automatisée](https://github.com/lougail/veille-tech-n8n)**<br>

`n8n` `Mistral Small` `Jina Reader` `Discord`

**[Pipeline NYC Taxi](https://github.com/lougail/brief-snowflake-dbt-nyc-taxi)**<br>

`Snowflake` `dbt` `SQL`

**[Churn Olist](https://github.com/lougail/brief-olist-churn)**<br>
